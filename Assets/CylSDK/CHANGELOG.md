# Changelog

## Version 1.0.0 (2025-07-08)
* Initial release of CylSDK.
* The following modules are included:
  * `CylSDK.Core`: Core utilities and extensions for Unity.
  * `CylSDK.Hexagons`: A module for working with hexagonal grids.
  * `CylSDK.StateMachine`: A state machine implementation for Unity.
  * `CylSDK.Utils`: Various utility functions and classes that are commonly used in Unity projects.
