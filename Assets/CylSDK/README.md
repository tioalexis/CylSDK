# CylSDK

This is a library that I have collected over the years to help me with my projects based on my experience as a 
professional Unity developer. It is a collection of useful functions and classes that I have found useful in my 
projects. It is not a complete library, but it is a good starting point for anyone who wants to use it. 

This library is designed to be used in Unity 6 and above. It is not compatible with earlier versions of Unity.
